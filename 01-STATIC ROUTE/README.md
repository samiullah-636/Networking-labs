# Static Routing Labs

## Overview
Static routing involves manually configuring routes on a router. It is best suited for small networks where the path is fixed.

## Labs

| Lab | Description |
|-----|-------------|
| [Basic Static](./basic-static/) | Configured static routes between 5 routers

## Prerequisites
- Basic understanding of IP Addressing
- Basic understanding of static route
- Cisco Packet Tracer installed

## Key Commands

Static route
```bash
ip route [network] [mask] [next-hop]
```

Verification
```bash
show ip route
```
