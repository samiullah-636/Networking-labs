# Networking Labs

---

## Each Lab Contains

- Topology diagram
- Device configurations
- Verification commands with output
- Packet Tracer file (.pkt)

---

## How to Use

1. Install **Cisco Packet Tracer** from [NetAcad](https://www.netacad.com)
2. Clone this repo
```bash
git clone https://github.com/samiullah-636/networking-labs.git
```
3. Open any topic folder and read its README
4. Open the .pkt file and follow along
